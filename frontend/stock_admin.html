DEPÓSITO

Stock

Controlá existencias y trazabilidad de cada material sin editar saldos manualmente.

Regla de Stock: Físico = lo que existe en depósito. Reservado = material comprometido por el sistema. Disponible = físico − reservado. Cada cambio se registra como un movimiento y queda en historial; un movimiento guardado no se reemplaza ni se borra.

Las reservas no se cargan manualmente en este bloque. Más adelante las generará el flujo de Liberación/Programación para que el Stock reservado tenga una fuente operativa real.

ALTA DE INVENTARIO

Registrar saldo inicial

El saldo inicial se registra una sola vez. Después, cualquier diferencia se corrige mediante un ajuste para conservar el historial.
